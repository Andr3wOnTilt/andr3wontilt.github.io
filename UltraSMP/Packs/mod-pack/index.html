Installazione

  1. Scarica UltraSMP-Mods.zip e scompattalo.
  2. Su CurseForge crea un'istanza Minecraft 26.3 con loader Fabric.
  3. Apri la cartella mods dell'istanza dal launcher CurseForge.
  4. Copia tutti i file .jar nella cartella mods.
  5. Avvia il gioco dal profilo Fabric.

Il file contiene solo le mod: non include configurazioni, texture o resource pack. Il Texture Pack è scaricabile separatamente.

Contenuto del pacchetto

7 mod per Fabric, compatibili con Minecraft 26.3. Il pacchetto non ha una versione propria: i file sono allineati alla versione di Minecraft indicata.

  • Fabric API 0.165.0
  • Simple Voice Chat 2.6.26
  • Sodium 0.9.2
  • Iris Shaders 1.11.7
  • Yet Another Config Lib 3.9.7
  • Fabric Language Kotlin 1.14.2
  • Zoomify 2.17.0
